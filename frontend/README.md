This frontend uses [Vite](https://vite.dev/) and supports Node.js 22.12.x and later within 22.x, 24.x, and 26+, including Node.js 26.13.

## Available Scripts

Run these commands from the `frontend` directory:

### `npm install`

Installs the frontend dependencies.

### `npm start`

Runs the development server at [http://localhost:3000](http://localhost:3000). The page reloads when source files change.

### `npm test`

Runs the frontend tests once.

### `npm run build`

Builds the production app into the `dist` directory.

### `npm run preview`

Serves the production build locally for verification.
